## 언어별 스테이지·튜토리얼 검증 필수

**KR·EN·JP는 같은 모드·스테이지라도 메뉴 순서와 등장 테마가 다를 수 있습니다.** 다른 언어의 튜토리얼을 번역하거나 공통 코드를 복사하는 것만으로 동작이 보장되지 않습니다.

- 튜토리얼, 스테이지 순서, 메뉴·레시피·재료 공급 또는 관련 생성기를 변경하면, 영향을 받는 각 언어의 실제 `.ow`에서 반드시 검사합니다.
- `stageMode` → `STAGE_CODE[Global.stage]` → `MENU_LIST`·`FRIDGE_LIST`·추가 재료 공급을 추적하고, `setHint` 실행 후의 실제 주문 목록(`currentMenu`·`loadingMenu`)과 조리 안내(`hintText`)를 비교합니다. 안내와 주문이 등장 테마에 맞고, 제공 재료와 레시피로 실제 조리 가능한지 확인해야 합니다.
- 튜토리얼 켜짐·꺼짐과 해당되는 연습 모드 진입 경로도 검사합니다. 생성기와 파일의 바이트 일치 검사는 필요하지만, 튜토리얼과 실제 게임 데이터의 일치 검사를 대신하지 않습니다.
- 화면의 스테이지 번호와 코드의 0 기반 인덱스를 구분하고, 검사 결과에 언어별 의도적 차이·튜토리얼 생략 여부와 게임 내 실행 검증 여부를 기록합니다.

### 회귀 방지 사례: 일본어판 캐주얼 다이닝 stage 8

2026-09-19 확인 기준, 일본어판 클래식 캐주얼 다이닝의 인덱스 7·10·13은 만두 테마 대신 생선 계열 테마를 사용합니다. 화면의 **stage 8은 `Global.stage == 7`**입니다. 이 위치에 만두 튜토리얼이 남아 생선 주문을 만두 주문으로 덮어쓰면서 진행 불가 문제가 발생했습니다. 일본어판의 해당 분기를 제거했으므로, 향후 다른 언어와 동기화할 때 되살리지 않아야 합니다. 테마에 맞는 대체 튜토리얼이 명시적으로 요청된 경우에만 다시 추가합니다. 메뉴 배치는 이후 변경될 수 있으므로 항상 최신 테이블을 확인합니다.
